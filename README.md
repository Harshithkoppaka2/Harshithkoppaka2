## What I’m working on

One of my current projects is **DriveSafe**, a rental operations platform built with React, Spring Boot, MySQL, and Docker.

The idea came from a simple problem: a car may technically be available, but that doesn’t always mean it’s actually ready to be handed over.

So I built the project around things like:

- vehicle maintenance readiness
- rental conflicts and extensions
- pickup and return inspections
- condition tracking
- making sure overdue vehicles don’t get assigned
